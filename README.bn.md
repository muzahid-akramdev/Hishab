# হিসাব (Hishab)

Expo (React Native) এবং Supabase দিয়ে বানানো একটি ব্যক্তিগত দৈনিক খরচ ও লাভ হিসাবরক্ষণ অ্যাপ।

এই গাইডটা লেখা হয়েছে **শুধু মোবাইল ফোন দিয়ে** (পিসি ছাড়াই) কাজ করার জন্য। এর জন্য আমরা
**Termux** নামের একটা অ্যাপ ব্যবহার করবো, যা ফোনের ভেতরেই একটা লিনাক্স টার্মিনাল চালু করে দেয়।
আসল APK বিল্ড হয় Expo-র নিজস্ব ক্লাউড সার্ভারে, তাই ফোনকে শুধু কোড আপলোড করলেই চলবে — ভারী
কম্পাইলিং কাজ ফোনে করতে হবে না।

---

## যা যা আগে থেকে লাগবে

- একটা অ্যান্ড্রয়েড ফোন (কমপক্ষে ৩–৪ GB ফাঁকা স্টোরেজ থাকলে ভালো)
- ওয়াইফাই কানেকশন (ডেটা বেশি খরচ হতে পারে, তাই মোবাইল ডেটার চেয়ে ওয়াইফাই ভালো)
- একটা Supabase অ্যাকাউন্ট ও প্রজেক্ট (ব্রাউজারে supabase.com থেকে)
- একটা Expo/EAS অ্যাকাউন্ট (ব্রাউজারে expo.dev থেকে ফ্রি সাইন আপ করা যায়)
- ঐচ্ছিক: **Expo Go** অ্যাপ (Play Store থেকে) — যদি বিল্ড করার আগে অ্যাপটা টেস্ট করে দেখতে চান

## ধাপ ১ — Termux ইনস্টল করা

⚠️ **Play Store-এর Termux ব্যবহার করবেন না** — সেটা পুরনো এবং অনেক কিছু কাজ করে না।
এর বদলে **F-Droid** থেকে ইনস্টল করুন:

1. ব্রাউজারে যান: `https://f-droid.org`
2. F-Droid অ্যাপটা ডাউনলোড ও ইনস্টল করুন (এটা একটা অ্যাপ স্টোর, Play Store-এর বিকল্প)
3. F-Droid খুলে সার্চ করুন **Termux**, ইনস্টল করুন
4. একইভাবে **Termux:API** নামের অ্যাড-অনটাও ইনস্টল করে রাখতে পারেন (ঐচ্ছিক, পরে কাজে লাগতে পারে)

## ধাপ ২ — Termux প্রস্তুত করা

Termux খুলে নিচের কমান্ডগুলো একটার পর একটা লিখুন (প্রতিটার পর Enter চাপুন):

```bash
pkg update -y && pkg upgrade -y
```

এরপর ফোনের স্টোরেজে অ্যাক্সেস দিতে:

```bash
termux-setup-storage
```

এটা চাপার পর অ্যান্ড্রয়েড একটা পারমিশন পপ-আপ দেখাবে — **Allow** করে দিন।

এবার দরকারি টুলগুলো ইনস্টল করুন:

```bash
pkg install nodejs-lts git unzip nano -y
```

ইনস্টল হয়ে গেলে চেক করুন:

```bash
node -v
npm -v
```

সংখ্যা দেখালেই বুঝবেন ঠিকমতো ইনস্টল হয়েছে।

## ধাপ ৩ — প্রজেক্টের zip ফাইলটা ফোনে আনা

1. Claude-এর চ্যাট থেকে **hishab.zip** ফাইলটা ডাউনলোড করুন — এটা সাধারণত ফোনের
   **Downloads / ডাউনলোড** ফোল্ডারে জমা হবে।
2. Termux-এ ফিরে এসে zip ফাইলটা নিজের হোম ফোল্ডারে extract করুন:

```bash
cd ~
unzip /sdcard/Download/hishab.zip -d ~/
cd hishab
```

> 📌 **গুরুত্বপূর্ণ:** প্রজেক্টটা অবশ্যই Termux-এর নিজের হোম ফোল্ডারে (`~/hishab`) রাখতে হবে,
> `/sdcard/...`-এ রেখে সরাসরি সেখানে কাজ করবেন না। শেয়ার্ড স্টোরেজে `npm install` অনেক সময়
> ব্যর্থ হয়, কারণ সেখানে সিমলিংক/পারমিশন ঠিকমতো কাজ করে না।

## ধাপ ৪ — ডিপেন্ডেন্সি ইনস্টল করা

```bash
npm install
npx expo install --fix
```

এই ধাপে বেশ কিছুটা সময় লাগতে পারে (ফোন ও নেটওয়ার্কের ওপর নির্ভর করে ৫–১৫ মিনিট) এবং ফোন কিছুটা
গরম হতে পারে। এই সময় ফোনটা চার্জারে লাগিয়ে রাখা ভালো এবং স্ক্রিন লক না করাই ভালো, নাহলে ইনস্টল
মাঝপথে থেমে যেতে পারে। স্ক্রিন লক এড়াতে চাইলে:

```bash
termux-wake-lock
```

## ধাপ ৫ — Supabase-এর তথ্য বসানো

ব্রাউজারে Supabase ড্যাশবোর্ডে যান → **Settings → API** → সেখান থেকে **Project URL** ও
**anon public key** কপি করুন।

Termux-এ ফিরে এসে:

```bash
cp .env.example .env
nano .env
```

`nano` খুললে ফাইলের ভেতর এরকম দেখবেন:

```
SUPABASE_URL=https://your-project-ref.supabase.co
SUPABASE_ANON_KEY=your-anon-key-here
```

আপনার কপি করা মানগুলো বসান (ব্রাউজার থেকে কপি করে Termux-এ **লম্বা প্রেস → Paste** করে পেস্ট
করতে পারবেন)। শেষ হলে:

- সেভ করতে চাপুন: `Ctrl + O`, তারপর `Enter`
- বের হতে চাপুন: `Ctrl + X`

`entries` টেবিলটা আগে থেকেই তৈরি ধরে নেওয়া হয়েছে, এবং তাতে RLS চালু আছে যাতে প্রত্যেক ব্যবহারকারী
শুধু নিজের সারিগুলোই দেখতে পায়। রেফারেন্স হিসেবে পলিসিগুলো এরকম হওয়া উচিত (Supabase SQL Editor-এ,
ব্রাউজার থেকে):

```sql
alter table entries enable row level security;

create policy "Users can manage their own entries"
on entries for all
using (auth.uid() = user_id)
with check (auth.uid() = user_id);
```

## ধাপ ৬ — EAS CLI ইনস্টল ও লগইন করা

```bash
npm install -g eas-cli
eas login
```

`eas login` চাপার পর ইমেইল/পাসওয়ার্ড চাইবে — expo.dev-এ যে অ্যাকাউন্ট বানিয়েছিলেন সেটা দিয়ে
লগইন করুন।

এরপর প্রজেক্টটাকে EAS-এর সাথে যুক্ত করুন:

```bash
eas build:configure
```

কোনো প্রশ্ন করলে (platform জিজ্ঞেস করলে) **Android** বেছে নিন। এটা স্বয়ংক্রিয়ভাবে
`app.config.js`-এ একটা EAS প্রজেক্ট আইডি বসিয়ে দেবে।

## ধাপ ৭ — Supabase সিক্রেট EAS-এ সেট করা

EAS Build চলে Expo-র ক্লাউড সার্ভারে, তাই ফোনের `.env` ফাইলটা সেখানে যায় না। তাই একই দুটো মান
আলাদাভাবে EAS-এ রেজিস্টার করে দিতে হবে:

```bash
eas env:create --scope project --name SUPABASE_URL --value "https://your-project-ref.supabase.co" --environment preview
eas env:create --scope project --name SUPABASE_ANON_KEY --value "your-anon-key-here" --environment preview
```

(এখানে `https://your-project-ref...` আর `your-anon-key-here`-এর জায়গায় নিজের আসল মান বসাবেন।)

## ধাপ ৮ — বিল্ড শুরু করা

```bash
eas build --platform android --profile preview
```

- প্রথমবার একটা Android কিস্টোর বানাতে বলবে — ডিফল্ট অপশন (সাধারণত Enter চেপে Yes) মেনে নিন।
- Termux আপনার কোড আপলোড করবে, তারপর বিল্ডটা Expo-র সার্ভারে হবে — একটা লিংক দেখাবে
  (`https://expo.dev/...`) যেখানে গিয়ে প্রগ্রেস দেখতে পারবেন।
- আপলোড হয়ে গেলে Termux ব্যাকগ্রাউন্ডে রেখে ফোনের অন্য কাজও করতে পারবেন, তবে অ্যাপটা যেন
  **কিল না হয়ে যায়** সেটা খেয়াল রাখুন (ব্যাটারি সেভার/অটো-কিল বন্ধ রাখুন Termux-এর জন্য)।

বিল্ড শেষ হতে সাধারণত ১০–২০ মিনিট সময় লাগে।

## ধাপ ৯ — APK ডাউনলোড ও ইনস্টল করা

বিল্ড শেষ হলে টার্মিনালে (এবং expo.dev ড্যাশবোর্ডে) একটা ডাউনলোড লিংক দেখাবে, যেমন:
`https://expo.dev/artifacts/...`

1. এই লিংকটা ফোনের ব্রাউজারে খুলুন (কপি করে Chrome-এ পেস্ট করলেই হবে)।
2. `.apk` ফাইলটা ডাউনলোড হবে।
3. ফাইলটাতে ট্যাপ করে ইনস্টল করুন। প্রথমবার অ্যান্ড্রয়েড "unknown sources থেকে ইনস্টল" নিয়ে
   সতর্ক করবে — যে অ্যাপ দিয়ে খুলছেন (যেমন Chrome বা Files) তাকে অনুমতি দিয়ে দিন।
4. **Hishab** অ্যাপ খুলুন, ইমেইল-পাসওয়ার্ড দিয়ে সাইন আপ করুন, এবং হিসাব লেখা শুরু করুন।

## ঐচ্ছিক — বিল্ড করার আগে অ্যাপটা টেস্ট করে দেখা

সরাসরি APK বিল্ড না করে আগে অ্যাপটা কেমন লাগছে দেখতে চাইলে:

```bash
npx expo start --tunnel
```

এটা একটা লিংক (`exp://...` বা QR কোড) দেখাবে। একই ফোনে থাকলে QR স্ক্যান করা কঠিন, তাই:

- Expo Go অ্যাপ খুলুন
- **Enter URL manually** অপশন বেছে নিন
- Termux-এ দেখানো লিংকটা কপি করে সেখানে পেস্ট করুন

এতে অ্যাপটা লাইভ প্রিভিউ হিসেবে চলবে, তবে চূড়ান্ত সাইডলোডযোগ্য APK পেতে হলে ধাপ ৮-এর মতো
`eas build` করতেই হবে।

## সমস্যায় পড়লে যা করবেন

- **টাইপ করা কঠিন লাগছে?** Termux-এ `Ctrl`, `Tab`, `Esc`-এর মতো কী দরকার হয় প্রায়ই। Play
  Store থেকে **Hacker's Keyboard** নামের একটা কীবোর্ড অ্যাপ ইনস্টল করলে এই কী-গুলো সহজে পাবেন।
- **ফাইল এডিট করা ঝামেলার মনে হচ্ছে?** `nano`-র বদলে **Acode** নামের একটা ফ্রি কোড এডিটর অ্যাপ
  ইনস্টল করে Termux-এর `~/hishab` ফোল্ডারটা সরাসরি ওপেন করে এডিট করতে পারেন।
- **`npm install` আটকে যাচ্ছে বা এরর দিচ্ছে?** প্রজেক্টটা `/sdcard/`-এর বদলে Termux-এর হোম
  ফোল্ডারে (`~/hishab`) আছে কিনা আবার নিশ্চিত করুন, এবং একবার `pkg upgrade -y` চালিয়ে দেখুন।
- **বিল্ড থেমে যাচ্ছে?** ফোনের ব্যাটারি অপ্টিমাইজেশন সেটিংসে গিয়ে Termux-কে "Unrestricted" বা
  "No restrictions" করে দিন, যাতে ব্যাকগ্রাউন্ডে চলার সময় অ্যাপটা বন্ধ না হয়ে যায়।

## পরিবর্তনের পর আবার বিল্ড করা

কোড বা ডিজাইনে কোনো পরিবর্তন করলে, শুধু আবার এই কমান্ডটা চালান:

```bash
eas build --platform android --profile preview
```

প্রতিবার একটা নতুন `.apk` তৈরি হবে, তার নিজস্ব ডাউনলোড লিংকসহ।
